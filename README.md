# Diamond Events – site

Site de prezentare pentru sala de evenimente Diamond Events (Săcălaz): sala, evenimente, galerie, verificare dată pe WhatsApp, hartă.

- Datele (WhatsApp, adresă, capacitate, poze, rețele sociale) se schimbă în `index.html`, la `EDITEAZĂ DOAR AICI`.
- Pozele se pun în folderul `poze/`.

# Finesse Detailing – site

Site de prezentare pentru Finesse Detailing (detailing auto). Programări pe WhatsApp.

- Datele (WhatsApp, locație, program, servicii, prețuri, produse, poze) se schimbă în `index.html`, la `EDITEAZĂ DOAR AICI`.
- Pozele se pun în folderul `poze/` și se trec în listele `gallery`, `beforeAfter` și `heroPhoto`.
